# Доминация USDT как индикатор рынка: что показывает метрика и что в неё вчитывают

Разбор показателя USDT.D — доли USDT в капитализации крипторынка, который широко используется как опережающий сигнал. Проверка проведена на собственных данных за 90 дней: разложение движения метрики на числитель и знаменатель, тест на опережение, проверка предложения USDT как самостоятельного сигнала.

**Вывод.** Движение доминации USDT на 97,3% определяется капитализацией остального рынка, а не поведением стейблкоина. Связь с рынком существует строго внутри одного дня и исчезает на горизонте суток. Вывод о рынке, полученный из этой метрики, представляет собой переописание уже случившегося движения цен.

**Дополнительно.** Крупнейшее за период изменение предложения USDT (1 083,2 млн $ 11 августа) оказалось не погашением, а переносом предложения между сетями: уход из Ethereum и появление в Tron за сутки. Суммарный ряд без разбивки по сетям показывает это как погашение миллиарда.

## Как воспроизвести

Нужен Python 3 и пакет `requests` (`python -m pip install requests`). Скрипты запускаются по порядку из одной папки, данные сохраняются в `data/`:

```
python scripts/usdt_dominance_collect.py     ~4 мин, 31 запрос к CoinGecko
python scripts/usdt_dominance_refine.py      ~7 мин, кэширует данные в coin_caps_wide.csv
python scripts/usdt_chain_breakdown.py       секунды, один запрос к DefiLlama
python scripts/diagnose_jumps.py             офлайн, по собранным данным
python scripts/export_chart_01_series.py     офлайн
python scripts/export_chart_02_series.py     офлайн
```

Скрипт `diagnose_jumps.py` записывает файл `data/jump_report.csv` только при обнаружении дневных скачков отдельных монет свыше 30%. В данных за период таких скачков нет, поэтому файл отсутствует — это результат проверки, а не пропуск.

Ключи доступа не требуются, используются только открытые интерфейсы. Повторный запуск на более позднюю дату даст другие значения: ряды привязаны к сроку среза.

## Источники

Первичные: CoinGecko (дневные капитализации монет), DefiLlama (предложение USDT и его разбивка по сетям), TradingView (значение USDT.D).

Вторичные использованы для сверки и как объект проверки: Decrypt (механика chain swap), Tokenpost (встречные переводы Tether Treasury и Binance 09.10.2026), «Ведомости» (общая капитализация рынка за неделю 17–23.08.2026), Kursiv (движение биткоина 20.08.2026). Полный реестр со ссылками — в разделе «Источники» самого кейса.

## Ограничения

Знаменатель построен по 29 монетам с полными данными за период: исторические ряды общей капитализации рынка у использованного источника недоступны в открытом доступе. Сверка с внешней оценкой показывает синхронное движение. Числитель проверен по двум независимым источникам, максимальное расхождение за 90 дней — 0,61%.

Цепочка транзакций за 11–12 августа не проверялась в блокчейне: вывод о переносе предложения между сетями опирается на совпадение сумм и дат с документированной механикой chain swap.
